# Update Probe จากลิงก์ release · มากับปลั๊กอิน 0.2.0

สกิลนี้ทดสอบว่าเครื่องของลูกค้าดาวน์โหลดไฟล์เวอร์ชันใหม่ได้เอง โดยไม่ต้องรอปลั๊กอินเวอร์ชันใหม่
**ทำตามขั้นตอนตรง ๆ ห้ามข้ามขั้น และห้ามหาทางอ้อมเมื่อเจอปัญหา** ให้หยุดแล้วรายงานข้อผิดพลาดตามจริง

🚨 **ห้ามให้ Claude พิมพ์เนื้อไฟล์ขึ้นใหม่เด็ดขาด** ไฟล์ต้องมาจากการดาวน์โหลดตรง ๆ เท่านั้น
ถ้าดาวน์โหลดไม่ได้ ให้รายงานว่าดาวน์โหลดไม่ได้ ห้ามคัดลอกเนื้อหาจากหน้าเว็บมาเขียนเป็นไฟล์เอง

## ขั้น 1 · รับลิงก์ release

ใช้ลิงก์ที่ผู้ใช้ให้มา ถ้ายังไม่มีให้ถามผู้ใช้ ลิงก์ต้องขึ้นต้นด้วย `https://` และชี้ไปที่ไฟล์ `release.json`

## ขั้น 2 · ดาวน์โหลด release.json

บันทึกไฟล์ลงโฟลเดอร์ scratchpad ของเซสชัน หรือโฟลเดอร์ทำงาน เพราะเครื่องมือ Artifact publish ได้เฉพาะไฟล์ในสองที่นี้

ใช้คำสั่งที่เครื่องมี เช่น `curl -fsSL -o release.json "<ลิงก์>"` หรือ Python `urllib.request`

- ดาวน์โหลดได้ = ไปขั้นถัดไป
- ดาวน์โหลดไม่ได้ = **หยุด** คัดลอกข้อความ error ลงรายงานทั้งหมด ข้อความนี้คือผลทดสอบที่สำคัญที่สุดของสกิลนี้

## ขั้น 3 · ตรวจ release.json

ไฟล์ต้องมีรูปแบบนี้

```
{
  "name": "maxxgpt-update-probe",
  "version": 2,
  "files": [ { "path": "probe.html", "url": "probe.html", "sha256": "..." } ],
  "capabilities": { ... }
}
```

- `name` ไม่ตรง = หยุดแล้วรายงาน
- `url` ของไฟล์ที่ไม่ขึ้นต้นด้วย `https://` ให้ตีความว่าอยู่ในโฟลเดอร์เดียวกับ `release.json`

## ขั้น 4 · ดาวน์โหลดไฟล์หน้าและตรวจ checksum

ดาวน์โหลด `probe.html` ตาม `url` แล้วคำนวณ sha256 ด้วย `sha256sum`, `shasum -a 256` หรือ PowerShell `Get-FileHash -Algorithm SHA256`

- ตรงกับค่าใน `release.json` = ผ่าน
- ไม่ตรง = **หยุด** รายงานค่าที่คาดไว้และค่าที่ได้ ห้าม publish

## ขั้น 5 · เตรียม capabilities

ใช้ค่า `capabilities` จาก `release.json`

ถ้ามีคำว่า `{{MAXXGPT_CONNECTOR}}` อยู่ ให้แทนด้วยชื่อ connector MaxxGPT ของบัญชีนี้ **แทนเฉพาะใน capabilities ห้ามแตะไฟล์หน้า**

วิธีหาชื่อ connector

1. เรียกสกิล `artifact-capabilities` ซึ่งจะแสดงรายชื่อ claude.ai connector ของเซสชันนี้ คู่กับ id ที่ใช้ในชื่อ tool
2. หา connector ที่มี tool `get_account_info` โดยดูจากชื่อ tool ในเซสชันที่เป็นแบบ `mcp__<id>__get_account_info`
   แล้วจับคู่ id กับชื่อที่แสดง ใช้ได้เฉพาะ claude.ai connector เท่านั้น MCP server ที่มาจากปลั๊กอินใช้ไม่ได้
3. เจอตัวเดียว = ใช้ชื่อนั้น · เจอหลายตัว = ถามผู้ใช้ · ไม่เจอ = บอกให้เพิ่ม connector ที่ claude.ai
   ไปที่ Settings และ Connectors ด้วย URL `https://mcp.maxxgpt.ai/mcp` แล้วหยุด
4. เรียก `get_account_info` หนึ่งครั้งเพื่อยืนยันว่าใช้ได้ tool นี้อ่านอย่างเดียวและไม่ต้องใส่อะไร

ประกาศ connector **ชื่อเดียว** เท่านั้น ห้ามใส่ชื่อสำรอง

## ขั้น 6 · หาหน้าเดิมแล้ว publish ทับ

1. เรียก `Artifact` ด้วย `action: "list"` และ `limit: 50` หาหน้าที่ชื่อ `MaxxGPT Update Probe` ทุกตัวอักษร
2. เจอ ให้เรียก `action: "read"` ที่ลิงก์นั้นก่อน แล้วจดตัวเลขหลังข้อความ `maxxgpt-update-probe version=`
3. publish ด้วย `file_path` = ไฟล์ที่ดาวน์โหลดในขั้น 4, `url` = ลิงก์เดิม, `capabilities` = ค่าจากขั้น 5
   ห้ามส่ง `icon`, `contract` และ `title`
4. ถูกปฏิเสธเพราะยังไม่ได้อ่านหรือเวอร์ชันชนกัน ให้ publish ซ้ำพร้อม `force: true` และจดไว้
   ใช้ได้อย่างปลอดภัยเพราะข้อมูลทดสอบอยู่ในฐานข้อมูลของหน้า และหน้านี้ไม่เคย publish ตัวเอง
5. ไม่เจอหน้าเดิม ให้บอกผู้ใช้ว่าต้องติดตั้งเวอร์ชันแรกด้วยสกิล `update-probe` ก่อน แล้วหยุด

## ขั้น 7 · ตรวจและรายงาน

อ่านหน้าอีกครั้ง ตัวเลขหลัง `maxxgpt-update-probe version=` ต้องตรงกับ `version` ใน `release.json` และลิงก์ต้องเป็นลิงก์เดิม

ส่งแบบฟอร์มนี้ให้ผู้ใช้ในกล่องโค้ด โดยเติมทุกบรรทัด

```
ผลทดสอบ update-probe-from-url
วันเวลา:
แอปที่ใช้: Claude desktop โหมด Cowork / Claude Code / อื่น ๆ
ลิงก์ release:
ดาวน์โหลด release.json: สำเร็จ / ไม่สำเร็จ พร้อมข้อความ error
checksum ไฟล์ที่ดาวน์โหลด: ตรง / ไม่ตรง
connector MaxxGPT:
หน้าเดิม: เจอ เวอร์ชัน N / ไม่เจอ
การ publish: ทับลิงก์เดิม / ทับลิงก์เดิมด้วย force / ล้มเหลว
ลิงก์:
เวอร์ชันหลัง publish:
ข้อผิดพลาดที่เจอ:
```

จากนั้นบอกผู้ใช้ให้เปิดลิงก์แล้วทำตามรายการ "สิ่งที่ต้องตรวจในรอบนี้" บนหน้า
**ห้ามสรุปว่าผ่าน จนกว่าผู้ใช้ยืนยันว่าเปิดหน้าแล้วเห็นตามรายการ**
