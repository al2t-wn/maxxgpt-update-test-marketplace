# Update Probe · รอบ Google Drive · ปลั๊กอิน 0.3.0

รอบนี้ตอบคำถามเดียว คือถ้าหน้าประกาศ connector ที่บัญชีไม่มี หน้าขออนุญาตจะแสดงอะไร และจะเด้งถามซ้ำทุกครั้งที่เปิดหน้าหรือไม่
คำตอบนี้กำหนดว่าสกิลติดตั้งของเว็บจริงต้องตัด connector ที่ลูกค้าไม่มีออกจากหน้าหรือไม่

**ทำตามขั้นตอนตรง ๆ ห้ามข้ามขั้น และห้ามหาทางอ้อมเมื่อเจอปัญหา** ให้หยุดแล้วรายงานข้อผิดพลาดตามจริง

## ขั้น 1 · ตรวจไฟล์แม่แบบ

ไฟล์อยู่ที่ `<Base directory ของสกิลนี้>/assets/probe.html` โดยใช้ Base directory ที่ระบบแจ้งตอนโหลดสกิล
คำนวณ sha256 ด้วย `sha256sum`, `shasum -a 256` หรือ PowerShell `Get-FileHash -Algorithm SHA256`

- ตรงกับค่าในตาราง = ผ่าน
- ไม่ตรง = **หยุด** รายงานค่าที่ได้ ห้าม publish

**ห้ามแก้ไฟล์นี้ และห้ามเขียนไฟล์นี้ขึ้นใหม่**

## ขั้น 2 · connector และ capabilities

เวอร์ชันนี้ขอใช้ connector 2 ตัว คือ MaxxGPT และ Meta ads ทำขั้นตอนนี้กับทีละ connector

1. เรียกสกิล `artifact-capabilities` ซึ่งจะแสดงรายชื่อ claude.ai connector ของเซสชันนี้ คู่กับ id ที่ใช้ในชื่อ tool
2. หา connector จาก tool ที่มันมี ไม่ใช่จากชื่อ โดยดูชื่อ tool ในเซสชันที่เป็นแบบ `mcp__<id>__<ชื่อ tool>`
   แล้วจับคู่ id กับชื่อที่แสดง ใช้ได้เฉพาะ claude.ai connector เท่านั้น MCP server ที่มาจากปลั๊กอินใช้ไม่ได้

| connector | tool ที่ใช้หา |
|---|---|
| MaxxGPT | `get_account_info` |
| Meta ads | `ads_get_ad_accounts` |

3. เจอตัวเดียว = ใช้ชื่อนั้น · เจอหลายตัว = ถามผู้ใช้ · ไม่เจอ = บอกให้เพิ่ม connector ที่ claude.ai
   ไปที่ Settings และ Connectors แล้ว**หยุด** และรายงานว่าไม่พบ connector ตัวไหน
   URL ของ MaxxGPT คือ `https://mcp.maxxgpt.ai/mcp` · URL ของ Meta ads คือ `https://mcp.facebook.com/ads`
4. ลองเรียกของจริงหนึ่งครั้งต่อ connector ถ้าได้ error ให้หยุด แล้วคัดลอกข้อความ error ลงรายงาน
   - เรียก `get_account_info` หนึ่งครั้ง tool นี้อ่านอย่างเดียวและไม่ต้องใส่อะไร
   - เรียก `ads_get_ad_accounts` หนึ่งครั้งด้วย `limit: 1` tool นี้อ่านอย่างเดียว ใส่ `client_conversation_id` เป็นตัวอักษรสุ่ม 20 ตัวจาก A-Z a-z 0-9 และใส่ `advertiser_request` เป็นคำขอของผู้ใช้ตามคำพูดของเขา
5. ตรวจว่าบัญชีนี้มี claude.ai connector ที่มี tool `search_files` หรือไม่ แล้วจดผลไว้ในรายงาน
   **ห้ามเรียก tool ของ Drive** รอบนี้ต้องการแค่รู้ว่ามีหรือไม่มี
   - ไม่มี = ตรงกับที่รอบนี้ต้องการ ทำต่อได้
   - มี = บอกผู้ใช้ว่ารอบนี้ออกแบบมาสำหรับบัญชีที่ไม่ได้ต่อ Drive แล้วถามว่าจะทำต่อเป็นกรณีเทียบหรือไม่

capabilities ที่ต้องส่งตอน publish คือ แทน `<ชื่อ MaxxGPT ที่พบ>` และ `<ชื่อ Meta ads ที่พบ>` ด้วยชื่อที่พบในข้อ 3
ส่วน `Google Drive` ให้ใส่ตามตัวอักษรนี้เสมอ เพราะรอบนี้ตั้งใจประกาศชื่อที่บัญชีอาจไม่มี

```
{"db": {}, "mcp": {"servers": [{"server": "<ชื่อ MaxxGPT ที่พบ>", "tools": ["get_account_info"]}, {"server": "<ชื่อ Meta ads ที่พบ>", "tools": ["ads_get_ad_accounts"]}, {"server": "Google Drive", "tools": ["search_files"]}]}}
```

นอกจาก Google Drive ให้ประกาศ connector ละ**ชื่อเดียว** ห้ามใส่ชื่อสำรอง

## ขั้น 3 · หาหน้าเดิม

1. เรียก `Artifact` ด้วย `action: "list"` และ `limit: 50` หาหน้าที่ชื่อ `MaxxGPT Update Probe` ทุกตัวอักษร
2. ไม่เจอ = บอกผู้ใช้ว่าต้องติดตั้งด้วยสกิล `update-probe` ก่อน แล้วหยุด รอบนี้ห้ามสร้างหน้าใหม่
3. เจอ ให้เรียก `action: "read"` ที่ลิงก์นั้นก่อน แล้วจดข้อความหลัง `maxxgpt-update-probe version=`

## ขั้น 4 · publish ทับลิงก์เดิม

- `file_path` = ไฟล์แม่แบบจากขั้น 1
- `url` = ลิงก์ของหน้าเดิม
- `capabilities` = ค่าจากขั้น 2
- ห้ามส่ง `icon`, `contract` และ `title`

ถ้าถูกปฏิเสธเพราะยังไม่ได้อ่านหน้าเดิม หรือเพราะมีเวอร์ชันใหม่กว่าชนกัน ให้ publish ซ้ำพร้อม `force: true` แล้วจดไว้
ถ้าถูกปฏิเสธด้วยเหตุผลอื่น ให้คัดลอกข้อความ error ลงรายงานทั้งหมด **ข้อความนี้เป็นผลทดสอบที่สำคัญ** เพราะอาจแปลว่าระบบไม่ยอมให้ประกาศ connector ที่บัญชีไม่มี

## ขั้น 5 · ตรวจหลัง publish

อ่านหน้าอีกครั้ง ข้อความต้องเป็น `maxxgpt-update-probe version=3` ตามด้วย `variant=drive` และลิงก์ต้องเป็นลิงก์เดิม

## ขั้น 6 · รายงาน

ส่งแบบฟอร์มนี้ให้ผู้ใช้ในกล่องโค้ด โดยเติมทุกบรรทัด

```

checksum แม่แบบ: ตรง / ไม่ตรง
connector MaxxGPT:
connector Meta ads:
บัญชีนี้มี connector ที่มี search_files หรือไม่: มี ชื่อ ... / ไม่มี
หน้าเดิมก่อนรอบนี้:
การ publish: ทับลิงก์เดิม / ทับลิงก์เดิมด้วย force / ถูกปฏิเสธ
ข้อความ error ถ้ามี:
ลิงก์:
ข้อความในหน้าหลัง publish:
```

จากนั้นบอกผู้ใช้สามเรื่อง

1. เปิดลิงก์ แล้วทำตามรายการ "สิ่งที่ต้องตรวจในรอบนี้" บนหน้า รายการของรอบนี้มีสี่ข้อท้ายเกี่ยวกับ Google Drive
2. ปิดหน้าแล้วเปิดใหม่อย่างน้อยหนึ่งครั้ง แล้วจดว่าหน้าขออนุญาตเด้งขึ้นเองหรือไม่
3. เมื่อจดครบแล้ว ให้พิมพ์ `/update-probe` เพื่อถอด Google Drive ออก แล้วเปิดหน้าใหม่อีกครั้ง จดว่าหน้าขออนุญาตหยุดเด้งหรือไม่

**ห้ามสรุปว่าผ่านหรือไม่ผ่าน จนกว่าผู้ใช้เล่าสิ่งที่เห็นกลับมา**
